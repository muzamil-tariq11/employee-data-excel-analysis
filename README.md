# Employee Data Excel Analysis

An end-to-end Excel-based data cleaning and analysis project, simulating a real-world messy dataset from an HR/employee records perspective.

## 📊 About the Project

This project demonstrates data cleaning, analysis, and dashboard creation using Microsoft Excel/WPS Spreadsheets — covering the full workflow a Data Analyst follows when working directly in Excel.

## 🛠️ Skills Used

- Data cleaning (handling missing values, inconsistent text formatting)
- Formulas: AVERAGE, SUM, MAX, MIN, IF, COUNTIF, SUMIF, PROPER, VLOOKUP
- Pivot Tables for department-wise and city-wise analysis
- Conditional Formatting to highlight key data points
- Chart creation for visual insights
- Dashboard design for executive-level summaries

## 🔍 What I Did

- Cleaned a messy 30-row employee dataset (missing values, inconsistent capitalization)
- Filled missing values using calculated averages
- Standardized text fields using the PROPER function
- Built Pivot Tables to summarize salary by department and city
- Created a Senior/Junior classification using IF formulas
- Applied Conditional Formatting to highlight high-salary employees
- Designed a dedicated Dashboard sheet with key metrics and a visual chart

## 📈 Key Insights

- **IT department** has the highest average salary among all departments
- Company-wide average salary is approximately **50,678**
- Salary range spans from **37,000** to **72,000**

## 📁 File Structure

- `Sheet1` – Raw and cleaned employee data
- Pivot Table sheet – Department-wise salary analysis
- `Dashboard` – Summary view with key metrics and chart
